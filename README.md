# Wedding Guest Analytics Dashboard

Wedding Guest Analytics Dashboard

### Interactive Excel Dashboard | Data Analysis & Visualization

## Project Overview

This project analyzes wedding guest attendance, RSVP decisions, and estimated reception expenses using Microsoft Excel.

The objective was to transform a guest list into meaningful business insights that support event planning, budgeting, and decision-making.

The project includes an interactive Excel dashboard, data summaries, visualizations, and a written stakeholder report.

## Business Questions

The analysis addresses four key questions:

How many guests are confirmed to attend?

How does attendance differ between guests invited by the bride and groom?

What is the distribution of adults and children?

What is the estimated reception cost, including sales tax?

## Key Findings

| Metric | Result |
|---|---:|
| Confirmed Attendees | 112 |

| Guests Invited by Bride | 50 |
| Guests Invited by Groom | 62 |
| Accepted RSVP Records | 59 |
| Declined RSVP Records | 67 |
| RSVP Acceptance Rate | 46.8% |
| **Estimated Reception Cost** | **$7,964.49** |

**Note:** The RSVP acceptance rate is calculated using guest-list records rather than individual attendees.

## Dashboard Features

The Excel dashboard includes:

- Six KPI cards displaying attendance and budget metrics

- Attendance comparison by bride and groom

- Adults versus children visualization

- Attendance analysis by relationship category

- An interactive PivotChart controlled by a relationship slicer

The slicer filters the interactive PivotChart. Other dashboard visuals display overall totals.

## Reception Cost Analysis

The estimated reception budget uses the following assumptions:

- Adult meal: $67.50
- Child meal: $47.25
- Sales tax: 8.25%
